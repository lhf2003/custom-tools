# 贾维斯功能全景

**创建日期**: 2026-07-30
**作者**: LHF & Claude
**版本**: v1.0
**状态**: 已批准

> 截至 2026-07-30，Alice 方法论路线图（`2026-07-28-CASE-001-贾维斯系统升级全盘路线图_01.md`）四期全部交付后的功能盘点。本文档是「现在有什么」的快照，规划与取舍以路线图为准。

## 一、人格层（他是谁）

- **设定集 persona.md**：叙事式身份证（你是谁/怎么说话/打死不做/分场合样子），运行时副本可编辑，核心身份区声明不可改
- **活人感状态**：时间带 × 忙碌度 × 关系阶段 → 叙事句注入聊天/日报——上午和深夜语气不同，结果一致
- **情感日记**：每晚一段私有日记（他看不到）→ 蒸馏「近期态度指引」注入聊天；情绪只走表达通道，执行通道不读
- **内心独白**：聊天里偶尔灰字「小声嘀咕」真实想法，可开关
- **今日关注**：前夜预规划当日关注清单，驱动聊天开场与弹窗时机
- **真实时间感知**：系统提示注入当前时间（模型本身没有时钟）

## 二、聊天（双通道降级链）

- **CC agent 通道**：claude CLI stream-json 驱动，`--resume` 多轮上下文，`--allowedTools mcp__companion__*` 只放 companion 数据工具
- **场景模型回退通道**：tool-use 循环（上限 4 轮、工具错误回传模型自纠、首轮 4xx 降级纯问答）——CC 未开时照样查数据/写笔记/记事实
- **降级链**：CC agent → 场景模型+工具 → 场景模型纯问答，每级质量下降而非功能消失
- **历史压缩**：rolling summary，未摘要 >24 条自动增量压缩（200 字内），保留最近 12 条原文；摘要段追加系统提示末尾
- **FIFO 排队**：两通道统一——在飞时新消息入队不打断，答完自动续发；取消清队列
- **能力手册激活**：粘贴错误堆栈 → 自动激活错误分析手册（现象/根因假设/定位建议/修复方向/预防措施）；能力目录可扩展

## 三、记忆系统

- **长期记忆**：五维分类（person/project/workflow/voice/expectation），逐会话提取（只提取用户消息，防自我强化），10 分钟防抖 + 21 点兜底
- **显式记忆**：说「记住…」立即记、「忘掉…」按关键词删（单次最多 5 条），全部写审计
- **记忆中心**：五维分组查看/编辑/删除，变更历史（add/confirm/update/delete）可查
- **经验本 evolution.md**：贾维斯自己写的工作经验（四小节：日报写作/弹窗分寸/分析提取/其他），注入各 prompt 形成「读经验→干活→写经验」闭环；16KB 上限

## 四、数据工具（11 个，MCP 与 function calling 双通道共用）

| 工具 | 能力 |
|------|------|
| get_activity_summary | 查电脑使用聚合（时间段双格式） |
| search_clipboard | 检索剪贴板历史 |
| get_habit_patterns | 查已学到的习惯模式 |
| list_memos | 查待处理备忘 |
| get_memory_facts / remember_fact / forget_fact | 查/记/忘长期记忆 |
| write_note | 写笔记（限「陪伴日报」目录） |
| create_suggestion | 提建议（进建议中心） |
| append_evolution | 写经验本（≤200 字/条，16KB 硬上限） |
| load_manual | 读能力手册全文 |
| propose_manual_edit | 提议修改手册（门控，不直接改） |

回退通道专属：`render_ui`（A2UI 界面卡片渲染）。

## 五、后台服务（不看管也在跑）

- **采集**：窗口活动轮询；源头标题脱敏（密码/银行/验证码等关键词 + 密码管理器进程 →「(已脱敏)」，下游接触不到原文）
- **每晚 21 点链**：模式挖掘 → 记忆提取兜底 → 情感日记 → 明日关注 → **日报**（触发时间声明在 reporter.md frontmatter，改文件免重编译；启动缺报补跑；CC agent/场景模型双路，agent 失败就地回退）
- **习惯模式**：应用组合/时间窗学习 → 晨间工作套装（一键批量启动）、情境联动
- **每周日晚 21 点**：弹窗处置统计（按类型四态：接受/拒绝/忽略/提示）→ 场景模型自评 → 写回经验本「弹窗分寸」节（防反馈循环偏差：成功案例一并统计；<5 样本只报数不下结论）

## 六、主动建议（弹窗有分寸）

- **剪贴板错误堆栈识别**：启发式（强标记+弱特征组合，宁漏勿滥）+ 冷却去重 →「检测到错误日志」→ 接受进聊天分析
- **可处置型**（带接受/忽略按钮）：错误分析、工作套装、手册修改提案
- **纯提示型**（推送即 seen，去按钮化）：休息提醒、今日备忘、日报通知、自动执行通知、备忘提醒
- **建议中心**：全历史可查（全部/待处理/已接受/已忽略/已提示五档筛选），待处理可补操作

## 七、进化治理（自进化的刹车）

- **版本快照**：任何程序化写入（经验本/态度指引/手册）前自动备份到 `companion/backups/`，每文件滚动保留 20 份；回滚前再快照当前版——回滚本身可回滚
- **确认门控**：手册修改必须经建议中心确认（manual_edit 卡）才生效；经验本追加、态度重写不门控（有快照兜底）
- **治理视图**（设置→陪伴→进化治理）：手册在线编辑（保存即快照，frontmatter 可改 schedule/enabled）、经验本容量条 + 一键整理（超 14KB 自动推提醒卡）、备份列表一键回滚

## 八、观测与成本

- **全量调用登记**：每次 LLM 调用记 llm_call_logs（来源/通道/模型/token/耗时/成本）——聊天、日报、分析、记忆提取、日记、摘要（chat_summary）、每周自评（weekly_review）、经验本整理（evolution_compact）全覆盖
- **观测面板**（设置→AI 模型页尾）：今日/昨日/近 7 天 × 来源，能回答「昨天日报/提取各烧了多少钱」

## 九、工程韧性

- MCP 注册失败重试 3 次（间隔 2s）；CLI 路径保存时校验可执行（警告不阻断）
- 聊天子进程/回退在飞状态异常复位（FlightReset 守卫，panic 不卡死队列）
- HTTP 客户端显式超时（connect 10s / 总 120s，防挂起请求卡死 FIFO）
