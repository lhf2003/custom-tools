## 背景与决策记录

为 FlowHub 制作对外产品官网（单页落地页），提示词喂给 AI 建站工具（v0 / Lovable / Bolt）自包含使用。经拷问式评审后定案如下：

| 决策点 | 定案 |
|---|---|
| 形态 | FlowHub 产品官网单页落地页 |
| 提示词消费者 | AI 建站工具（自包含，工具无关格式） |
| 主 CTA | GitHub 引流（「在 GitHub 查看」） |
| 视觉语言 | 延续产品深色 zinc + Signal Indigo 点睛（DESIGN.md），放宽 18px 字级上限 |
| 文案语言 | 纯中文（技术词保留英文） |
| 产品视觉 | 首屏 CSS 复刻启动器窗口 + 功能区块截图占位（生成后手动换真图） |
| 内容叙事 | 工具为主、贾维斯压轴，六区块结构 |
| 技术部署 | 不限定技术栈（仅约束纯前端、无后端依赖） |
| 首屏标语 | 「唤起，输入，完成。」 |

## 提示词全文

直接复制以下代码块内容，粘贴给 AI 建站工具：

```markdown
# 任务
为 Windows 桌面效率工具「FlowHub」生成一个单页产品官网（落地页）。纯前端、无后端依赖；技术栈由你决定（单文件 HTML 或静态站点项目皆可）。全部文案使用简体中文。

# 产品事实（不得虚构除此之外的功能）
- FlowHub 是 Windows 平台的桌面效率中枢（类似 uTools / Raycast），全局快捷键 Ctrl+Shift+Space 唤起
- 五大功能：应用启动器（模糊搜索）、剪贴板历史、密码本（AES-GCM 加密、本地存储）、Markdown 笔记、文件搜索（集成 Everything）
- 差异化功能：AI 陪伴搭子「贾维斯」——每日活动摘要、工作习惯建议、陪伴日报
- 技术栈：Tauri 2.0 + Rust + React 18 + TypeScript + SQLite，本地优先，数据不出本机
- 项目地址：https://github.com/lhf2003/custom-tools

# 页面目标
让访客产生「这是一个被精心打磨的工具」的信任感，并点击主按钮「在 GitHub 查看」。访客是开发者与 Windows 效率工具爱好者。

# 设计规范（严格遵守，这是产品的品牌语言）
**整体气质**：精致、现代、克制。参考 Raycast / Linear 官网的深色质感。明确禁止：SaaS 营销风的糖果感、AI 产品常见的满屏渐变/霓虹/渐变文字/装饰粒子、玻璃拟态滥用、卡片套卡片。

**色彩**（深色单色系，禁止引入灰色系以外的表面色）：
- 页面背景 #1c1c1e～#27272a 的 zinc 深色；表面分层只用：#27272a（基座）/ #2d2d2d（卡片）/ #3f3f46（悬浮）
- 文字：主 #f4f4f5，次 #d4d4d8，辅助 #a1a1aa
- 品牌靛蓝 #6366f1：全页点睛色，任意单屏面积 ≤10%，只用于品牌标识、关键强调；深色背景上的靛蓝文字一律用 #818cf8
- 操作蓝 #2563eb：主按钮底色，hover 加深至 #1d4ed8
- 列表/区块选中态与 hover 提亮：白色 5%/10% 透明纱层（#ffffff0d / #ffffff1a）
- 状态色仅用于语义：成功 #22c55e / 警告 #f59e0b / 错误 #ef4444

**字体**：系统字体栈 `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`，禁止加载 Web 字体。字级：Hero 标语 48–64px/600，区块标题 28–32px/600，正文 16px/1.6，辅助说明 14px。层级靠字重与灰阶，不靠花哨排版。

**形状与阴影**：圆角只用 6/8/12/16px，禁止超过 16px。表面静止时平坦无阴影（Flat-at-Rest）；阴影只响应状态：浮起层 `0 8px 32px rgba(0,0,0,0.3)`，首屏产品窗口 `0 25px 60px rgba(0,0,0,0.6)`。

**动效**：150–300ms，ease-out 或 cubic-bezier(0.4,0,0.2,1)；滚动入场用克制的透明度+轻微位移；`prefers-reduced-motion` 下降级为即时显示。禁止弹性曲线、粒子、视差花哨效果。

# 页面结构（六个区块，按此顺序）

## 1. Hero
- 上方居中（或左对齐）品牌名「FlowHub」+ 一句话定位
- 主标语（48–64px）：**唤起，输入，完成。**
- 副标题（16–18px，#d4d4d8）：启动器、剪贴板、密码本、笔记与陪伴，整合在一个随时唤起、即用即走的窗口里。
- 按钮组：主按钮「在 GitHub 查看」（#2563eb 底白字，8px 圆角，链接到上文仓库地址）；次按钮「了解功能 ↓」（幽灵按钮，透明底 #a1a1aa 字，hover 铺 #ffffff1a）
- **首屏核心视觉：用代码复刻 FlowHub 启动器窗口**（不是图片），规格：
  - 宽 640–720px，12px 圆角，背景 rgba(39,39,42,0.7) + backdrop-blur，1px 白色 10% 描边，阴影 0 25px 60px rgba(0,0,0,0.6)
  - 顶部搜索框：透明底、18px、左侧搜索图标（#a1a1aa），placeholder「搜索应用、功能…」（#8e8e96）
  - 下方 3–4 行搜索结果假数据（如 Visual Studio Code、剪贴板历史、JSON 格式化）：每行 8px 圆角、12px 内边距、32px 图标方块 + 14px 名称；第一行为选中态：底 #ffffff1a、名称文字 #818cf8
  - 底部状态栏：12px 辅助文字「↑↓ 选择 · ↵ 打开 · esc 关闭」（#a1a1aa）
  - 窗口后方允许最多一处极微弱的靛蓝径向光晕（透明度 ≤8%），除此之外背景保持干净的 zinc 深色

## 2. 核心链路
三个 kbd 风格的按键块横向排列：`Ctrl+Shift+Space 唤起` → `输入关键词` → `↵ 完成`，配一句说明：全程双手不离键盘，不打断心流。kbd 样式：#2d2d2d 底、6px 圆角、等宽感、1px 灰阶描边。

## 3. 功能矩阵
标题「一个窗口，五件利器」。五个功能项（每项：简洁线性图标 + 标题 + 不超过两句文案 + 16:10 截图占位）：
- **应用启动器**：模糊搜索本机应用与内置功能，回车即开
- **剪贴板历史**：复制过的都在，随时找回
- **密码本**：AES-GCM 加密，主密码解锁，数据只存在本机
- **Markdown 笔记**：想法随手记，文件存储，不被锁定
- **文件搜索**：集成 Everything，全盘文件秒级直达
截图占位样式：#2d2d2d 底、12px 圆角、居中显示 14px #a1a1aa 文字「截图：{功能名}」，不得使用任何外链占位图服务。

## 4. 贾维斯（差异化区块，压轴但不花哨）
标题：「工具之外，多一个懂你的搭子。」
文案：贾维斯是你的 AI 效率搭子。一天结束时，它会生成一份陪伴日报：今天的时间花在哪、发现了什么习惯模式，以及一两条真诚的建议。不打扰，只在你需要时出现。
配一个克制的日报卡片 mock（#2d2d2d 底、12px 圆角、无阴影）：卡片标题「陪伴日报」，三行示例摘要文字。

## 5. 技术栈与信任
标题「为 Windows 精心打造」。三个要点横排：
- **本地优先**：剪贴板、密码、笔记全部存储在本机
- **Tauri 2.0 + Rust**：内存占用小，唤起毫秒级
- **开源**：代码完全公开，欢迎 Star 与贡献

## 6. 页脚
再次放置主按钮「在 GitHub 查看」，下方一行小字：FlowHub — Windows 桌面效率中枢 © 2026

# 质量红线
- 正文与背景对比度 ≥4.5:1（含占位文字）
- 全部交互键盘可达，焦点态清晰可见
- 响应式：移动端单列布局，启动器窗口宽度自适应
- 语义化 HTML，设置 <title>「FlowHub — Windows 桌面效率中枢」与 meta description
- 不要发明本提示词之外的功能、数字与评价；不要使用 emoji 作为功能图标；不要浅色模式
```

## 落地后跟进项

1. **截图替换**：生成产物中搜索「截图：」即可定位全部占位符，按 16:10 比例截取应用真实界面替换（可用 `npm run tauri:dev` 启动后逐模块截图）。
2. **README 承接流量**：仓库根目录当前无 README，从官网点进 GitHub 的访客会扑空，需补一个与官网同文案体系的 README。
