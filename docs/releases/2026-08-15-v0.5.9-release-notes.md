## 新功能

### 贾维斯接入第三方 MCP 工具
贾维斯聊天现在不仅能调用内置工具，还能接入第三方 MCP 服务提供的工具：

- **两种接入方式**：远程 HTTP 服务，或本地命令行程序
- **JSON 一键导入**：兼容 Claude Desktop 的 `mcpServers` 配置格式，粘贴即导入
- **服务卡片管理**：每张卡片显示连接状态与工具数量，支持启停、配置、删除、刷新工具清单
- **调用日志**：每个服务的工具调用记录可逐条追溯（最近 50 条）
- **结果安全隔离**：外部工具返回的内容会做安全标记，避免被误当作指令执行

### 记忆中心精简
- 移除陪伴设置页的「学习概览」区（今日使用统计）
- 「学到的习惯模式」迁入记忆中心统一查看，可分组折叠、忽略
- 记忆五分类文案对齐，成本说明更精炼

## 设置优化
- MCP 服务管理并入「工具」页，第三方服务配置改为独立页面，操作更聚焦
- 「内置 MCP server」更名「本地 MCP 服务」，新增复制配置按钮，一键粘贴到外部 AI 客户端使用
- 工具页分组默认折叠，页面更清爽
- SKILL 页只展示自己导入的手册，内置手册由系统统一维护更新

## 体验优化
- 聊天流式回复渲染优化，长回复滚动更流畅、不卡顿
- 修复聊天中行内代码被误渲染成引用块的问题

## 问题修复
- **本地 MCP 服务**：修复启动命令含空格或特殊字符时启动失败、服务无响应时界面卡死的问题
- **天气**：切换城市后自动清空旧城市天气缓存，避免「张冠李戴」
- **文件搜索**：修复输入法组合态误触发打开、首次搜索闪帧、空结果时隐藏常用文件、@ 触发词参数回填等问题
- **断网保护**：修复网络异常时聊天可能卡住、冻结的问题
- **本地服务防代理劫持**：联网搜索与本地 MCP 服务改为直连，避免被系统代理劫持导致健康检查死循环
- **聊天恢复**：切换视图后恢复进行中的请求，保住「取消」按钮
- **权限更严格**：堵住 shell 敏感路径的绕过方式（目录尾、相对路径等）
- **凭证安全**：服务 token 不再明文回传前端显示
