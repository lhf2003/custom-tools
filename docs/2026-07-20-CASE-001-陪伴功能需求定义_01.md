## 一句话定义

常驻数字伙伴：想到的那一刻用一句话扔给系统，系统在正确的时间把它还给你；同时系统自己学习你的行为链，用"毕业制"逐步放权自动执行。

## 定位与信条

- **定位**：主动秘书 · 工作生活平权 · 编程外围僚机
  - 代码本体是各项目 Claude Code 会话的领地，本系统**不碰开发工作本身**
- **信条**：信噪比 > 智能。宁可漏弹，不可错弹。被无视 = 死亡

## 线 1：意图暂存「记」（B2）

用户主动暂存的意图，系统保管并在正确情境归还。

| 环节 | 定义 |
|---|---|
| 捕获 | `Alt+Space` 唤起启动器 → 输入「记 xxx」→ 回车（2 秒完事） |
| 解析 | 原文保真永不动；LLM（闲聊场景模型）异步解析 `{时间/人/渠道/关键词}` 仅作触发索引；解析失败也保留，靠晨间兜底 |
| 呈现 ① | 每日首次电脑活动 → 单张汇总 Toast「今天有 N 条备忘」（每日仅一次） |
| 呈现 ② | 前台窗口标题命中关键词 → 弹出该备忘 |
| 呈现 ③ | 声明渠道（微信/钉钉等）→ 打开该 IM 即弹出备忘 + 话术；未声明渠道 → 窗口标题含人名时弹出（现代 IM 主窗口标题不含聊天对象，2026-07-20 实测修正） |
| 闭环 | 手动划掉为主；7 天未动自动降级不弹（不删，可考古） |

**触发语义**：`due` 日期前不参与 ②③ 触发；`due` 当天起参与。

## 线 2：场景联动（B3）

系统从活动流水学习**行为链**「A 之后你通常做 B」：

- **序列型**：开机 → 微信 → 飞连 → IDEA（固定启动序列）
- **情境型**：15:00 × 在工作 → 打开音乐（时间 × 当前状态 → 行为）

**毕业制放权**：

```
前 3 次：弹卡片请示（「要放音乐吗？」）
被接受 3 次 → 毕业：直接执行 + 事后轻告知
被忽略 2 次 → 降频；被拒绝 2 次 → 永久停用
```

**执行边界**：自动执行只到「打开应用」为止，不碰凭证与登录态。

## 地基：个人记忆层

- **沉淀**：关于用户的持久事实（如「张三=前端同事」「写代码时听 Lo-fi」）
- **消费**：日报更有个人感、意图解析更准、建议文案更个性化
- 随 B3 建设（habit_patterns 升级为行为链时一并落地）

## 统一原则

你记的（intent）+ 它建议的（error/long_work/daily_report）= **同一个 suggestions 体系**：同一张表、同一个 Toast 窗口、同一个晨间面板、同一套划掉/过期生命周期。仅卡片上以来源标识区分（📌 备忘 vs 系统建议）。

## 验收标准

- **B2**：真实使用一周 —— 暂存 ≥5 条、②③ 触发命中 ≥2 次、误弹 ≤1 次；出差回来对接场景不再卡壳
- **B3**：开机序列毕业一次；音乐联动被拒后不再打扰
- **反标准**（两线通用）：用户开始无视弹窗 = 失败，立即砍触发频率
