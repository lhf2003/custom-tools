### MEDIUM

**M1. 折叠态锚定补偿可越界** — `src/modules/launcher/LauncherView.tsx:182`
命中条目异步插入第一位时 `setSelectedIndex(i => i+1)` 做对象锚定，但折叠态 `navItems = allResultsWithMemory.slice(0, collapsedCount)` 长度不变（插入把末项顶出窗口）。用户在补偿前已选中最后可见项（index 8）→ 补偿后 index 9 越界：视觉无选中、Enter 因 `items[selectedIndex]` 为 undefined 静默无效（不会误启动，方向键可自愈）。时序窗口小（250ms 防抖+embedding 返回前用户已下移到底），但建议在补偿处 clamp 到可视长度。

**M2. `<button>` 内嵌套可交互元素** — `src/modules/memory/SourceCard.tsx:135-161`
CardShell 根是 `<button>`，VideoCard 时间段 chips 用 `span role=button` 内嵌其中——违反 HTML 内容模型（button 内不允许 interactive content），a11y 树会扁平化。事件冲突已用 stopPropagation 处理、实践可工作；建议 CardShell 根改 `div role="button"` 或将 chips 区移出 button。

**M3. `memory_recent` limit 无上限** — `src-tauri/src/commands/memory.rs:151`
`limit.unwrap_or(60)` 直接进 SQL LIMIT。参数绑定无注入风险，本地通道威胁面低，但建议 clamp（如 ≤500）防未来调用方误传。

### LOW

1. **dev-cm-spike 验证页进 release 构建**（`vite.config.ts:29`）——作者已注「临时，验证后移除」，跟进删除即可。
2. **Favicon 负面缓存**（`Favicon.tsx:9`）——抓取失败的 null 也入 Promise 缓存，本会话不再重试；可接受，知悉。
3. **内联动态类型导入**（`LauncherView.tsx:265`）——`(hits as import('@/modules/memory/types').MemoryHit[])` 可提为顶部 `import type`，纯风格。
4. **`baseUrl` 前后端尾斜杠语义微差**——前端 `replace(/\/$/,'')` 只去一个，后端 `RTRIM(...,'/')` 全去；仅影响 `//` 结尾畸形 url 的聚合键，无实际后果。
5. **popup 列表 slice(0,4) 极端裁剪**（`popup.js:59`）——同时索引 ≥2 视频且均不在最近 3 条时，被裁的 indexing 任务不展示且 `anyIndexing` 误判停轮询；概率极低。
6. **memoryEntry 与 plugin.ts 双处硬编码**（`LauncherView.tsx:155`）——name `'记忆检索'`/path `'builtin://memory'` 与插件 manifest 耦合，改名需两处同步。
