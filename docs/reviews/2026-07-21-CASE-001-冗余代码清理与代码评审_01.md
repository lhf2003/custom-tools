## 二、评审发现与处置

### 已修复

| 级别 | 问题 | 处置 |
|---|---|---|
| HIGH | companion-toast 窗口未配置 capabilities，前端 `listen`/`hide` 可能无权限 | 新建 `capabilities/companion-toast.json` 最小权限集 |
| HIGH | `db.rs` 迁移用 `let _ =` 吞掉所有 ALTER 错误 | 新增 `add_column_if_missing`，仅忽略 duplicate column，其他错误上报 |
| HIGH | `CompanionToast.tsx` 倒计时在 setState updater 中执行副作用，且新建议到达时存在旧回调竞态 | 改为 elapsed 时间计算 + `suggestionIdRef` 守卫 |
| MEDIUM | `get_companion_intents` 应用层过滤导致 limit 语义错误 | 新增 `db::list_intents`，SQL 层过滤 `suggestion_type='intent'` |
| MEDIUM | 时间乘法溢出风险 | `saturating_mul`（mod.rs、analyzer.rs） |
| MEDIUM | `LauncherView.tsx` 死变量 `allResults` | 删除 |
| MEDIUM | `cargo fmt --check` 失败 | 已执行 `cargo fmt` |
| LOW | `parseInt` 缺基数（2 处） | 改为 `Number()` |

### 未修复（记录待决）

| 级别 | 问题 | 说明 |
|---|---|---|
| CRITICAL(存疑) | `agent.rs` `Command::new(bin_path)` 未校验 | bin_path 是用户显式配置的 claude CLI 路径（功能本身即"执行用户指定的二进制"），`Command::new` 不经 shell 无注入面；本地单机应用威胁模型弱。是否加白名单校验属设计决策，待 LHF 确认 |
| MEDIUM | `act_on_companion_suggestion` async 命令内执行同步 SQLite/进程启动 | 实际耗时毫秒级，影响小；如需严格可改 `spawn_blocking` |
| MEDIUM | `LauncherView` 未 memo 的回调被 `useCallback` 闭包捕获（handleBrowserPaste 等） | 当前回调不依赖组件状态，仅为未来风险，未动 |
| MEDIUM | `debouncedResize` 无清理、视图切换后可能残留触发 | 全应用一致模式，影响极小，未动 |
| 既有问题 | ESLint 配置损坏：`eslint.config.js` 用 ESLint 9 API（`eslint/config`）但 package.json 锁 `eslint@^8.57.0`，`npm run lint` 无法运行（stash 验证为既有问题） | 需升级 eslint 9 + typescript-eslint 8，或回退配置写法，待决策 |
