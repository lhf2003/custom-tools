# 备忘数据独立重构设计（memos 表）

**创建日期**: 2026-07-29
**作者**: LHF（设计裁决，grilling 定稿）/ Jarvis（实现）
**版本**: v1.0
**状态**: 已批准

## 背景：双源不同步缺陷

「记 xxx」备忘原为**双写**：`suggestions` 表（status=pending）+ 笔记文件「陪伴日报/备忘.md」（`- [ ]` checkbox）。用户在笔记页勾选 checkbox 是纯文本编辑，没有任何回写机制——DB 永远停在 pending。两个修改入口彼此不可见，导致已完成的备忘仍出现在晨间汇总、情境弹窗和聊天问答里。

## 裁决记录（grilling 逐项定稿）

| # | 问题 | 裁决 | 理由 |
|---|---|---|---|
| 1 | 唯一真源 | **DB 表**，md 降级为历史档案 | 备忘带状态机+结构化触发器，天然属于 DB；md 解析无法可靠承载 |
| 2 | 是否独立成表 | **独立 memos 表** | suggestions 回归纯系统建议/通知流；备忘不带 suggestion_type/source 等异质概念 |
| 3 | 情境触发弹窗 | **保留** | 「记」区别于普通便签的核心价值：到场景自动浮现 |
| 4 | LLM 重构正文 | **双文本**：content_raw 保真 + content 重构；剥时间词+元话、保留人物（B 方案）；失败兜底=原文 | 快速输入是电报文体，不适合展示；「问张三报价单发了吗」不能剥成「报价单发了吗」（丢动作主体） |
| 5 | 状态机 | **三态** pending/done/dismissed + acted_at | 完成与忽略对日报是两种素材（正反馈 vs 沉默数据）；7 天降级保持查询时逻辑，不污染状态 |
| 6 | 存量 intent | **直接删，不迁移** | 省掉一整类迁移 bug |
| 7 | 笔记页形态 | **DB 驱动备忘视图**（侧栏置顶虚拟节点）；md 停写留档；日报数据源切 list_memos 工具 | 入口跟着用户习惯走；双源问题连根拔掉 |

## 表结构

```sql
CREATE TABLE memos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    content TEXT NOT NULL,        -- LLM 重构的展示文本
    content_raw TEXT NOT NULL,    -- 用户原文，保真永不动
    status TEXT NOT NULL DEFAULT 'pending'
        CHECK (status IN ('pending', 'done', 'dismissed')),
    acted_at INTEGER,             -- 处置时间
    due_date TEXT,                -- YYYY-MM-DD，LLM 从原文提取
    trigger_data TEXT,            -- JSON {keywords, person, channel}
    last_triggered_at INTEGER,    -- 情境弹窗同日不重复
    created_at INTEGER NOT NULL
);
```

设计点：无 title/body 之分（那是系统建议的历史包袱）；trigger_data 保持 JSON blob（SQL 从不按内部字段过滤），due_date 拆列（每次查询都要比较）。

## 架构变化

```
记 xxx ──► memos 表（content=原文）──► LLM 异步解析 ──► 写回重构正文+触发器+due
                                            │（失败：正文兜底原文，每小时补解析 ≤2 条/次）
消费方（全部读 memos 表）：
  晨间汇总（memo_is_active：7天降级+due过滤）
  情境弹窗 ──► suggester::push_suggestion(intent_reminder)
  日报上下文 / list_memos 工具（MCP+场景双通道）
展示面：
  笔记模块「备忘」虚拟节点 ──► list_memos / set_memo_status 命令
  （勾选 done ↔ 取消回 pending；悬停 × dismissed）
```

**关键语义**：情境弹窗改走系统建议流（intent_reminder 类型建议卡）——**忽略弹窗 ≠ 处置备忘**，memos 状态只有用户在笔记视图明确勾选才变。suggestions 表纯化为"主动通知流"。
