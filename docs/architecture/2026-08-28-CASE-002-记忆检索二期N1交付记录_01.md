## 交付范围

N1 = WeMM 正式空间落地（裁决 CASE-007 的 N1 阶段）。embedding 引擎从 bge+onnxruntime 切换为 WeMM-Embedding-2B Python sidecar，存量 604 条记忆全量重 embed 至 2048d 向量空间，bge 完全卸载。

## 架构形态

```
nervis 主进程 (Rust/Tauri)
  └── SidecarEmbedder (nervis-memory/src/sidecar.rs)
        │  stdio [u32 LE][JSON] 帧
        └── python sidecar/wemm/server.py (WeMM-Embedding-2B, bf16, GPU)
              └── 模型: tencent/WeMM-Embedding-2B (2048d, ~5.1GB)
```

- **sidecar 生命周期**：按需拉起（首次 embed 调用）→ 空闲 30 分钟自动回收 → Drop 发 shutdown 干净退出
- **协议**：ping / embed_documents / embed_query / embed_image / embed_video / shutdown，握手 loading → ready / error(gpu_required)
- **路径解析**（resolve_default）：
  - python: `NERVIS_WEMM_PYTHON` > `sidecar/wemm/.venv`（开发）> `{app_data}/wemm-venv`（生产 uv sync 落点）> PATH
  - server: `NERVIS_WEMM_SERVER` > exe 祖先目录找 `sidecar/wemm/server.py`
  - model: `NERVIS_WEMM_MODEL_DIR` > `sidecar/wemm/models` > `{app_data}/models/wemm-embedding-2b`

## schema 迁移（v1→v2）

| 变更 | 说明 |
|---|---|
| `memory_items` 加 `modality` 列 | text / image / video，老数据默认 text，N2/N3 用 |
| `memory_vectors` DROP 重建 | bge 512d → WeMM 2048d，旧向量空间不兼容直接废弃 |
| `expires_at` 全清 NULL | Q9 全永久裁决，推翻一期 90 天滚动 |
| `migration_pending` 标记 | 迁移后由 memory-backfill --remigrate 重 embed 清除 |
| 保留期配置/purge 调度撤除 | store.rs 删 4 函数、commands 删 2 个、lib.rs 删 24h 定时器 |

## 环境引导（N1-5c）

- **uv.exe**（52MB）随 NSIS 安装包分发至安装根目录，零网络依赖建 venv
- **设置页记忆中心**新增「本地模型环境」状态卡：GPU / Python 依赖 / 模型三状态灯 + 一键安装 + 进度条
- 安装流水线：`uv sync`（依赖 ~2.5GB）→ `download_model.py`（模型 ~5.1GB hf-mirror），进度走 `memory-env-progress` 事件
- venv 落 `{app_data}/wemm-venv`（Program Files 不可写），模型落 `{app_data}/models/wemm-embedding-2b`

## bge 卸载

- `embed.rs` 删除，`ort`/`tokenizers` 依赖从 Cargo.toml 移除

- 本机残留 `%APPDATA%/com.flowhub.app/models/bge-small-zh-v1.5` 可手动删

## 踩坑记录

| 坑 | 根因 | 解法 |
|---|---|---|
| Mutex 自死锁 | `call()` 持锁调 `arm_watchdog()` 二次 lock | 先 drop(state) 再 arm，deadline 持锁前算好 |
| cargo run --example 不重建 bin | example 和 bin 是独立编译目标 | 改了 crate 必须显式 `cargo build --bin` |
| 孤儿 sidecar 堆显存 | 杀父进程不杀子进程，多实例各占 5.1GB | `taskkill /T` 杀进程树 |
| batch=32 显存 swap | naive attention 平方复杂度 | remigrate BATCH=8（N0 验证值） |
| WAL 裸 cp 迁移失败 | 数据在 -wal 文件 | `sqlite3.connect().backup()` 在线备份 |
| PyPI Windows torch 只有 +cpu | 清华镜像同源 | pytorch-cu128 专用源（阿里云镜像） |
| torchvision 版本记错 | torch 2.8 ↔ torchvision 0.23，不是 0.28 | 以本机实际安装版本为准 |
| tauri resources 目录打包跟随 junction | `../sidecar/wemm` 整目录会把 4.5GB 模型打进安装包 | 改逐文件 map 形式 |
| uv sync 慢速（0.4MB/s） | download.pytorch.org 海外 CDN | pip 缓存提取 wheel 本地 path 安装 |
