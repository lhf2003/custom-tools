# 文档分片语义化与增量索引（CASE-003）

**创建日期**: 2026-09-02
**作者**: LHF + Claude
**版本**: v1.0
**状态**: 已批准

## 背景

原 `chunk.rs` 分片实现存在六个问题（按收益排序）：

1. **双重截断不一致**：`content.js` 采集上限 20,000 字符，但 `MAX_CHUNKS=8 × 1200 = 9,600`——长文只有前 48% 进索引，后半永不入索引（召回漏洞），且尾部变更不触发重 embed
2. **机械硬切无视语义边界**：`chars.chunks(1200)` 在句子甚至词中间断开，embedding 质量与 snippet 展示双损
3. **块间零重叠**：跨边界语义检索时两头都弱
4. **标题未注入块内容**：Readability 抽出的正文块缺少主题锚点（「它」「这个功能」等指代失锚）
5. **去重全删全写**：块级哈希只用于「全文未变」判定，同 URL 改个 typo 全文重 embed
6. **多块路径未 trim**（小修）

## 决策（LHF 拍板）

| # | 决策点 | 结论 |
|---|--------|------|
| D1 | overlap 归属 | **只进 `embed_text`，不进 `content`/哈希**——content 干净（snippet 无冗余），去重精准 |
| D2 | 哈希语义 | **`content_hash` 对 `embed_text` 计算**——标题变更触发全文重 embed（语义正确）；前块变更仅扩散到相邻块 |
| D3 | `MAX_CHUNKS` | **直接删除**——采集端各有上限（网页 2 万字符 ≈ 17 块），host 帧长 `MAX_FRAME_BYTES` 兜底 |

## 设计

### chunk.rs：语义分片

```rust
pub struct Chunk {
    pub content: String,     // 入库：纯块内容（句 join "\n"，无重叠无前缀）
    pub embed_text: String,  // embed 输入：[标题\n\n][前块尾句\n]content
}
pub fn chunk_text(title: Option<&str>, text: &str) -> Vec<Chunk>
```

- **切句**：`\n` 拆段 → 段内句末标点切句（中文 `。！？；…` 必断；英文 `.!?;` 要求后随非字母数字，避免 `example.com`/`v1.2` 误切），逐句 trim 去空
- **贪心打包**：句累积到 1200 字符封块；单句超长按 1200 硬切兜底
- **overlap**：块尾最后一句 ≤150 字符整句带进下一块 `embed_text`（超长硬切片取尾部 150 截断）
- **标题注入**：截 100 字符，仅进 `embed_text`

### store.rs：plan/commit 增量索引

原 `index_document`（全删全写）拆为两步：

- `plan_index(conn, source, dedup_key, chunks)`：比对存量 `(id, content_hash)`，按哈希匹配标 `reuse_rowid`（同内容块移动位置也复用，同哈希多块按 id 序消费）
- `commit_index(conn, meta, planned, embeddings)`：事务内删多余旧行+向量 → 复用块 UPDATE 元数据（**rowid/向量不动**）→ 新块 INSERT 行+向量
  - 全部复用且行数一致 → `SkippedUnchanged`（不触碰 indexed_at）
  - 并发兜底：commit 内校验复用行仍属本 key（按 source+dedup_key 隔离实际不可达）
- `IndexOutcome::Indexed { total, embedded }`：调用方可观测实际 embed 块数
- 便捷封装：`index_chunks`（文本文档一站式）、`index_single_with_vector`（视频段等向量已算好的单块）

### 单块路径不注入标题

字幕段/视频段/主图/fact/剪贴板图的 `embed_text == content`——哈希算法变更（content → embed_text）对单块无影响，**存量单块数据零重 embed**；仅网页正文/笔记（多块）首次重访时按新分片全量重 embed 一次，之后进增量稳态。零主动迁移。

### 顺带收益

- 主图/剪贴板图：plan 先行，内容未变**跳过 `embed_image`**（原流程先 embed 后判重，图片推理白做）
- `fact_pipeline` 手写哈希预检删除，由 `plan_index` 统一承担

  - store（内存库）：全量写入、未变跳过、**小编辑只重 embed 变更块（embedded=1，复用块 rowid/向量原样保留）**、删块清理、缺向量报错

## 影响面

- 知识页/启动器/扩展**零改动**；snippet 质量自动受益（块首为完整句子）
- 网页正文 embedding 输入含标题+overlap 前缀，检索语义增强；`content` 入库文本不变（展示口径不变）
