## 交付范围

### 后端（主进程集成 nervis-memory）

- `commands/memory.rs`：`memory_search(query, k)` / `memory_open(id)` 两个命令，`spawn_blocking` 执行（embed ~10ms + vec0 扫描 ~10ms，不阻塞主线程）
- `MemoryEmbedderState(Arc<Mutex<Option<Embedder>>>)`：**懒加载**——首次检索才加载 95MB 模型，启动零成本；之后常驻 ~150MB（预算 300MB 内）
- `lib.rs` setup 首行 `register_vec_extension()`（先于 `db::init` 一切开库）
- `init_ort` 幂等化（OnceLock，重复调用安全）
- 打开行为：browser/subtitle → 后端 `open::that`（字幕 URL 自带 `#t=` 秒级锚点）；note → 前端跳 markdown 视图；clipboard 等 → 内容回前端复制 + toast

### 前端（启动器融合，D5 的 C+B 落地）

- `MemoryResults.tsx`：`MemoryStrip`（C 分组 ≤3 条）+ `MemoryList`（s 模式全量 8 条），行样式与 ItemRow 一致（bg-white/10 选中），来源徽章 浏览/字幕/笔记/剪贴板/记忆
- **C 分组**：普通查询 ≥2 字符时 250ms 防抖并行检索，应用结果置顶不动，下方「记忆 · 你可能在找」分组异步流入；出现时分组撑高窗口 148px；陈旧响应用请求序号守卫
- **键盘**：↓ 溢出最后一行应用 → 进记忆分组（独立 memorySel 选中态）→ 再 ↓ 到「展开」按钮；↑ 从分组首条回网格末项；Enter 打开；无记忆命中时行为与旧版完全一致（肌肉记忆零影响）
- **`s ` 前缀模式**：独占全量语义视图（列表布局，步长 1，导航集合 = 记忆条目映射 `memory://<id>`，复用全套键盘机器）；Enter 防抖冲刷分支已排除记忆模式（防误启动应用）
- 检索失败（模型未就绪/无索引）静默缺席，不打扰主流程
