## 交付范围

### M1 内部管线（src-tauri workspace 化）

- **`crates/nervis-memory` 共享 crate**：`chunk.rs`（1200 字符切块/xxh3 哈希/可索引性预判）、`embed.rs`（bge-small-zh-v1.5 fp32，ort `load-dynamic`，查询侧指令前缀，512 token 截断，CLS+L2 归一化）、`store.rs`（sqlite-vec 封装：建表/去重索引/检索/过期清除/按域删除）
- **表结构**：`memory_items`（元数据+dedup_key+content_hash+expires_at）+ `memory_vectors`（vec0，float[512]），进 flowhub.db
- **memory-host**：native messaging 独立二进制（u32 LE 长度前缀 + JSON 帧），消息：index / index_subtitle / clear_browsing / delete_domain / ping；browser/subtitle 自动打 90 天 expires_at
- **memory-backfill**：回填 + `--search` 检索验证工具
- **回填结果**：剪贴板 263 行 + 笔记 49 篇 → 495 chunks，重跑全跳过（幂等）

### M2 浏览器链路（extension/）

- **MV3 扩展**：content.js（10s 停留阈值、Readability 抽取、密码框整页排除、SPA 路由检测、<200 字符弃采）、subtitle.js（B站/YouTube 字幕 DOM 捕获 + currentTime 时间戳、30s/20 段冲刷）、background.js（native port + storage.session 持久队列 + alarms 保活重连 + 黑名单 + 统计）、popup（D13 仪表盘，DESIGN.md token 对齐）
- **字幕 45 秒窗口合并**（D7 修正实现）：host 侧按 `floor(start/45)` 合段，单行字幕不做独立向量（太短无检索价值），URL 带 `#t=窗口起始秒` 支撑段落跳转
- **scripts/install_native_host.py**：manifest + Chrome/Edge HKCU 注册（支持 --uninstall）
- **依赖落位**（出货形态预演）：onnxruntime.dll 随 exe 同目录，模型在 `app_data/models/bge-small-zh-v1.5/`，环境变量仅作覆盖项

## 工程坑位记录（后续勿踩）

1. `sqlite3_auto_extension` 只对注册**之后**打开的连接生效——任何进程必须 `register_vec_extension()` 先于 `Connection::open`。
2. MV3 service worker 30s 空闲即被杀：内存队列/定时器全丢。队列必须 `storage.session` 持久化，周期重连只能 `chrome.alarms`。
3. 浏览器拉起的 host 进程**没有 shell 环境变量**：ORT_DLL 与模型路径必须有默认落位（exe 同目录 / app_data 默认路径），env 仅作覆盖。
4. cargo  rebuild 前需杀残留 memory-host.exe（Windows 文件锁，os error 5）。
5. rusqlite `query_map` 迭代器先 `collect` 再 `?`（NLL）。
