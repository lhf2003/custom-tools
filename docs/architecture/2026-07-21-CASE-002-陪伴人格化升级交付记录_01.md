## 一句话概述

陪伴功能从「无名系统助手」升级为有统一人格的数字搭子**贾维斯**：设定集驱动的跨触点一致人格、可读写的自进化经验本、ChatView 闲聊通道改造为 Claude Agent SDK 协议驱动的 agent 入口（可查用户真实数据）。

## 产品决策（LHF 拍板，2026-07-21）

| 决策点 | 结论 |
|---|---|
| 名字与身份 | 就叫**贾维斯** |
| 人格基调 | **互联网搭子**（非英伦管家）——说人话、可用梗、吐槽事不吐槽人、数据说话 |
| 人味分布 | Toast 零戏 · 日报结尾一句「今日蛐蛐」 · 聊天全量人格 |

## 体系架构

### 双文件制（PROTECTED / MUTABLE 分离）

```
persona.md     身份证：你是谁/怎么说话/打死不做的事/不同场合的样子/信条
               （模型只读，任何人不可改；给模型看的世界观，不含人写说明）
evolution.md   经验本：日报写作/弹窗分寸/分析提取/其他 四小节
               （模型可读可写，自进化载体）
```

- 内嵌默认版在 `src-tauri/src/companion/`，首次调用时由 `persona.rs` 播种到 `app_data_dir/companion/`
- 运行时以副本为准（persona 可手动编辑；evolution 由 agent 经 MCP 追加）；读取失败回退内嵌版
- **播种语义**：只在副本不存在时播种——改内嵌默认版后需删除副本重新播种

### 注入点矩阵

| 触点 | 注入内容 | 通道 |
|---|---|---|
| 每日分析（21:00） | persona + evolution + 三维提取/不该存（内联任务规则） | 场景 LLM 单次调用 |
| 日报 agent（21:00） | persona + evolution + 步骤化任务说明 + 「今日蛐蛐」空间 | claude CLI + MCP |
| 聊天（ChatView） | persona + evolution + memory_facts + 聊天场合规则 | claude CLI stream-json |
| Toast 建议卡 | 静态文案口吻统一（零小剧场） | Rust 模板 |

### 自进化闭环

```
经验本注入 prompt（读）→ agent 干活 → append_evolution 写回（写）→ 次日再注入（读）
```

- MCP 工具 `append_evolution(section, lesson)`：小节白名单（日报写作/弹窗分寸/分析提取/其他）、单条 ≤200 字、文件 16KB 上限、最新条目插在小节标题下
- 写经验只经日报 agent（MCP 通道）；单次分析调用无写通道

### 聊天 agent 通道（Claude Agent SDK 协议）

参考 [Agent SDK 官方文档](https://code.claude.com/docs/zh-CN/agent-sdk/overview)：SDK 本质是对 `claude` CLI 流式协议的封装，本项目以 Rust 直接驱动同一协议（无 Node 依赖）。

```
ChatView（贾维斯 · 全人格）
  └─ jarvis_chat_send(text)
       └─ spawn claude CLI（隔离工作区 companion-agent）
            -p <text>
            --output-format stream-json --verbose --include-partial-messages
            --resume <持久化会话 id>          # 多轮上下文续接
            --append-system-prompt <persona+evolution+facts+聊天规则>
            --allowedTools "mcp__companion__*"  # 只读数据工具，碰不到文件系统
            --max-turns 8
            env ENABLE_TOOL_SEARCH=false      # 关键：headless 下 MCP 工具可见
       └─ NDJSON 逐行解析 → jarvis:chunk（文本增量）/ jarvis:status（工具活动）/ jarvis:done（成本）/ jarvis:error
```

- **单飞控制**：新消息或取消即 kill 旧进程（`JarvisChatChild` 托管状态）
- **会话持久化**：claude session id 存 settings 表（`companion_chat_claude_session`），重启可续；「清空对话」同时调 `jarvis_chat_reset` 重置 agent 上下文
- **前端**：闲聊标签改「贾维斯」（Sparkles · 品牌 Indigo）；工具活动时状态栏显示「贾维斯在翻数据（工具名）…」；错误日志预填充从 qa 改投 chat

## 使用注意

1. **成本与延迟**：每条闲聊消息走 claude agent，查数据的消息约几美分、首 token 冷启动 2-5s；高频闲聊可考虑后续拆「快聊（场景模型）/深问（agent）」双通道
2. **CLI 兼容性**：旧版 CLI 不支持 `--include-partial-messages` 时去掉该 flag 即可（解析器两种模式兼容）
3. **qa 历史会话**仍存于数据库，仅入口移除
4. **今晚 21:00** 为首次「带身份证 + 经验本」的日报/分析运行

## 验收方式

1. `npm run tauri:dev` → 聊天发「我今天用了哪些应用」→ 应看到「贾维斯在翻数据…」→ 带真实数据的搭子腔回答
2. 追问「哪个最久」→ 验证 `--resume` 多轮上下文
3. 清空对话后再问 → 验证上下文已重置
4. 明早查看 evolution.md 是否被写入第一条经验
