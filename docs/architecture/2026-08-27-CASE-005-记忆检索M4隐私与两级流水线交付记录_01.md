## 交付范围

### 隐私控制（D10 全链路）

- **黑名单单真源迁移 SQLite**：`memory_blacklist` 表（domain PK）；扩展 `chrome.storage.local` 降级为缓存——SW 启动/连通时先重放离线增删（`nervis_pending_ops`）再拉全量覆盖；keepalive alarm 每 30s 同步一次（设置页改动 ≤30s 生效于扩展）。拉黑即物理删除该域存量索引
- **保留期可配**：`memory_meta` kv 表存 `retention_days`（默认 90）；memory-host 每次 Index 现读（改设置无需重启 host）
- **purge 调度落地**：主进程启动即 `purge_expired` 一次 + tokio 24h 周期（此前只有函数无执行点）
- **设置页 UI**：记忆中心新增「浏览记忆与隐私」一节——来源统计（页面/字幕段）、保留期选择（30/90/180/365）、黑名单增删、一键清除浏览索引（danger confirm）

### memory-host 协议扩展

- 新增 `get_blacklist` / `block_domain` / `unblock_domain` / `focus_app` 四个请求
- **req_id 回显**：Response 带可选 `req_id`，扩展侧新增 `callNative`（请求-响应，3s 超时）与既有入队通道并存；无 req_id 的回包忽略
- `focus_app`：拉起同目录主 exe（候选名 nervis.exe/FlowHub.exe/flowhub.exe 按存在性探测），单例插件聚焦已有窗口——popup「打开记忆库」按钮就此接线

### remember_fact 两级流水线（D12）

- **facts 向量化**：source='memory_fact'、dedup_key='fact:{id}'、不过期；`sync_fact_index` 差异对账（哈希预检，未变更不重复 embed；索引孤儿随 forget 清理）；memory-backfill 已回填 34 条存量 facts
- **流水线**：向量召回 top score ≥ 0.65 → 小模型裁决 ADD/UPDATE/NOOP（`Scene::Companion` 配置，登记 llm_call_logs source=remember_fact_arbitrate）；无命中直接写入
- **降级链**：Embedder 不可用 → bigram 查重；LLM 失败/回复无法解析 → bigram 查重（原行为完整保留为安全网）
- **阈值标定**：决策路径写审计事件 source 字段（`explicit|vec=0.88|llm:update`），跑一段时间后按分布收 RECALL_THRESHOLD（初值 0.65 只影响「是否打扰 LLM」，不影响正确性）
- **进程适配**：MCP 模式（无 AppHandle）抽 `resolve_scene_provider_with_dir` / `call_scene_model_llm_with_dir` 复用同一观测通道；`block_on_llm` 双形态（MCP 同步进程自建 runtime / app 内 tokio 上下文 block_in_place）；`run_mcp_server` 首行 `register_vec_extension`
