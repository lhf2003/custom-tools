# 外观配置与浅色主题设计

**创建日期**: 2026-08-06
**作者**: LHF
**版本**: v1.0
**状态**: 已批准

## 背景

设置页的「外观」tab 目前是纯占位页（主题预览卡片 + "即将推出"文案，导航标记 `soon`）。
本设计将其合并进「通用」tab，并落地第一版外观配置：主题模式（跟随系统/深色/浅色）与窗口不透明度。

现状盘点：

- `AppearanceSettings.tsx` 占位页：`ThemeMiniPreview` 深/浅卡片 + 规划中文案
- `settingsStore` 与 Rust `settings` 表已存在 `theme: 'system'`、`window_opacity: 0.95` 字段（Rust 已 clamp 0.5~1.0），但前端无任何 UI 使用
- `index.css` `:root` 已有全套 `--app-*` 语义变量；**但 `tailwind.config.js` 的 `app-*` 颜色是硬编码色值，非 `var()` 引用** —— 这是浅色主题的最大障碍，Tailwind 类不跟随 CSS 变量
- `THEME.ts` 常量被 11 个文件 import 用于 inline style（JS 静态值，不响应主题切换）
- `VditorEditor.tsx` 中 `theme: 'dark'` 硬编码
- `index.css` 窗口兜底样式（`.css-glass-fallback` 等）硬编码深色
- 窗口 `transparent: true` → Tauri 2.0 `set_opacity` 可用
- 陪伴界面（toast）全 token 化（`text-app-brand-primary-light` 等），浅色自动跟随，零适配

## 决策汇总（grilling 确认）

| # | 决策 | 结论 |
|---|------|------|
| 1 | 一期范围 | 主题模式三项（跟随系统/深色/浅色）+ 窗口不透明度；**不做**材质（Mica/Acrylic）与字号 |
| 2 | 切换机制 | CSS 变量 + `data-theme`：`[data-theme='light']` 覆盖全套变量；THEME.ts 11 处 inline style 改 `var()` 引用；`:root` 默认深色 |
| 3 | vditor/jsonCanvas | 跟随主题：vditor 内置 light/dark 主题 + 少量 token 覆写对齐设计系统；导出 content-theme 同步 |
| 4 | 页面布局 | 导航删除「外观」项及 `soon` 标记；外观分组插在「窗口」组之后；PageHeader 描述更新 |
| 5 | 主题控件 | 三卡片式选择：`ThemeMiniPreview` 扩展 `system` 变体（半深半浅预览），选中品牌色描边 |
| 6 | 不透明度交互 | 拖动实时 `set_opacity`（新增专用命令，只改运行时）→ 松手 `set_setting` 落库一次；滑块 50%~100% 步进 5% + 百分比 |
| 7 | AI surface | 一期跟随：生成时把当前主题传给 LLM prompt，A2uiTheme 已支持 `theme` 字段，质量用 prompt 设计规范兜底 |
| 8 | 浅色色板 | zinc 浅色阶反向映射（同色系同源不同明度）+ 品牌色深档变体（AA）+ 黑色透明度系 + 阴影加深 + 窗口兜底浅色版 |

## 浅色色板设计（`[data-theme='light']`）

与深色基座同源（zinc），明度反向映射，遵守 DESIGN.md Even Tiers Rule：

| 语义 | 深色（现状） | 浅色（新增） |
|------|-------------|-------------|
| bg-primary | `#1e1e21` | `#fafafa` |
| bg-secondary | `#26262a` | `#f4f4f5` |
| bg-tertiary | `#2e2e33` | `#e4e4e7` |
| bg-elevated | `#38383e` | `#d4d4d8` |
| bg-pressed | `#45454c` | `#a1a1aa` |
| text-primary | `#f4f4f5` | `#18181b` |
| text-secondary | `#d4d4d8` | `#3f3f46` |
| text-tertiary | `#a1a1aa` | `#52525b` |
| text-disabled | `#71717a` | `#a1a1aa` |
| text-placeholder | `#9a9aa2` | `#71717a` |
| bg-hover/active | `rgba(82,82,91,0.5)` | 黑色系低透明度 |
| brand-primary | `#6366f1` | `#6366f1`（不变） |
| brand-primary-light | `#818cf8` | `#4f46e5`（深档保证 AA） |
| 透明度变体 | white 系 | 覆盖为 black 系（rgba(0,0,0,.05/.10/...)） |
| 阴影 | 0.2 alpha | 微调加深档 |
| 窗口兜底/panel | 深色半透明 | 浅色半透明 + 黑边框 |

**tailwind.config.js 关键改造**：`app-bg/app-text/app-border/app-brand` 全部从硬编码色值改为 `var(--app-*)` 引用，使 Tailwind 类跟随 CSS 变量；zinc-600/700/800 重映射保留但同样改 `var()` 引用（memory: 勿删，存量 bg-zinc-* 自动跟随）。

## 实现清单

1. **CSS 变量层**：`index.css` 加 `[data-theme='light']` 全套覆盖（背景/文字/边框/品牌/状态/透明度/阴影/tooltip/窗口变量）；窗口兜底样式浅色版
2. **tailwind.config.js**：色值改 `var()` 引用
3. **THEME.ts**：11 处 inline style 改 `var(--app-*)`（SettingsView、ClipboardView、MarkdownView、PasswordView、EverythingView、JsonFormatterView、ContextMenu、DeleteConfirmDialog、EmptyState、MemosView 等）
4. **主题应用逻辑**：settingsStore 加 `setTheme`/`setWindowOpacity`；App 启动应用主题到 `data-theme`；`matchMedia('(prefers-color-scheme: dark)')` 监听跟随系统（仅 `system` 模式生效）
5. **Rust**：新增 `set_window_opacity` 专用命令（运行时 `set_opacity`，不落库）；落库走已有 `set_setting`（clamp 0.5~1.0 已有）
6. **设置页合并**：SettingsView 删外观导航项；GeneralSettings 插「外观」分组（窗口组后）：三卡片主题选择 + 不透明度滑块；删 AppearanceSettings.tsx；PageHeader 描述更新
7. **vditor**：`theme: 'dark'` 硬编码改动态；浅色用内置 light + token 覆写；`export.ts` content-theme 跟随
8. **AI surface**：生成 prompt 传当前主题
9. **验证**：`npm run build`（类型检查必须走 build，npx tsc --noEmit 假阳性）+ `cargo build` + 切主题目测各模块

## 不做（本期）

- 窗口材质（Mica / Acrylic）——占位文案继续保留"即将推出"
- 界面字号 / 品牌强调色自定义
- 陪伴界面专属适配（token 化已自动跟随，无需工作）

## 实现变更（2026-08-06 提交前）

- **窗口不透明度从一期移除**：tauri 2 无内置 opacity API 需走 SetLayeredWindowAttributes（实现已验证可编译），提交前随插件系统回退一并移除；前端 ThemeController/settingsStore/GeneralSettings 中的透明度调用已同步删除。后续若恢复，按决策 6 的交互设计实现（专用命令 + 松手落库）
- `theme`/`window_opacity` 字段保留于 settings 表与 store（默认值不变），仅 UI 未暴露
