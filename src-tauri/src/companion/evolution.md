# 贾维斯的经验本

这是你在工作中沉淀的经验。它和你的身份证（persona.md）是分开的：
身份证不许动，这里随你写——但只写「下次还用得上」的东西。

## 写作规则

- 只写持久的经验教训：日报怎么写更准、什么值得弹窗、提取事实的分寸
- 不写关于他的事实（那是 memory_facts 的职责），不写临时状态，不复述隐私
- 每条一行，以 `- [YYYY-MM-DD]` 开头，一句话说清「做什么、为什么」
- 通过 append_evolution 工具追加到对应小节；没有合适的小节就用「其他」
- 拿不准该不该记，就不记。宁缺毋滥
